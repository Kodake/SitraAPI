# SITRA

SITRA is a minimal API project built with .NET 8 that serves as the backend project.

## Prerequisites

Before you begin, ensure you have met the following requirements:

- .NET 8 SDK: [Download .NET 6](https://dotnet.microsoft.com/download/dotnet/8.0)

## Getting Started

To get started with SITRA, follow these steps:

1. Clone this repository:
   ```bash
   git clone https://github.com/Kodake/PosAPI.git

2. Navigate to the project directory:
   ```bash
   cd SITRA

3. Build and run the API:
   ```bash
   dotnet run

4. Your API should now be running at https://localhost:5001 or https://localhost:5001/swagger/index.html.
   You can test it using your favorite API client.
